# Мимимиметр (Spring Boot Web)

Веб-приложение для выбора самого милого котика путём парного голосования с формированием итогового рейтинга участников.
Ссылка на задание: https://github.com/i-novus-llc/job-test/tree/master/mimimimetr

## Требования перед запуском
* Установленный **JDK 17** или выше.
* Браузер для работы с веб-интерфейсом.

## Инструкция по запуску

### 1. Клонирование репозитория
Откройте терминал и скачайте проект на компьютер:
```bash
git clone https://github.com/FFWasd/TestTask.git
cd TestTask
```

### 2. Запуск приложения
Выполните команду в корневой папке проекта (где находится файл `pom.xml`):
* **Для Windows (PowerShell / CMD):**
  ```powershell
  .\mvnw.cmd spring-boot:run
  ```

* **Для Linux / macOS / Git Bash:**
  ```bash
  ./mvnw spring-boot:run
  ```

*(При первом запуске Maven автоматически загрузит необходимые зависимости, это может занять 1–2 минуты. Дождитесь появления в консоли строки `Started ...Application`).*

### 3. Открытие в браузере
После успешного запуска сервера перейдите по адресу:
**[http://localhost:8080](http://localhost:8080)**

### 4. Остановка сервера
Чтобы остановить работу приложения, нажмите **`Ctrl + C`** в окне терминала, где запущен сервер.

## Что сделано
* У всех котов есть имя
* Пары для голосования перебираются по принципу "каждый с каждым" пока не закончатся все варианты
* Пользователь не видит повторения пар
* Пары должны подбираются случайно для каждого пользователя
* Более 5 котиков (они предустановлены после деплоя приложения)
* Проголосовать можно кликнув по имени или по фотографии
* Когда все пары закончатся, показывает топ 10 котиков

## Что не сделано
* Приложение должно быть многопользовательским
* Топ формируется из суммы голосов всех пользователей
